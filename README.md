# 🏨 Hotel Manager · Android

**Часть Hotel Manager — системы для небольшой гостиницы.**

Код проекта написан нейросетью по задачам и требованиям **[TheUnclePeka](https://github.com/TheUnclePeka)** для личного пользования в своей маленькой гостинице. Эта обезличенная версия опубликована на GitHub для тех, кому она может понадобиться. Можно использовать и изменять проект под свои задачи на условиях [MIT](LICENSE).

Независимый репозиторий, лицензия MIT.

Предварительная версия 0.2.0. Реализованы аккаунты и роли, приглашения QR/JSON, отдельные защищённые профили, ротация сессий и ограничение офлайн-доступа до 24 часов. Это проверочная сборка, не готовый публичный выпуск.

Исходные данные, история частного проекта, сертификаты и ключи не импортированы. Использование общей модели и интерфейса фиксируется локальными пакетами в vendor/.

## Разработка

Node.js 24+, JDK 21, Android SDK 36; переменные `JAVA_HOME` и `ANDROID_HOME`. Минимальная версия пока унаследована из исходника: Android 15 / API 35. Старые версии Android ещё не проверены.

```sh
npm ci
npm run sync
```

Для тестового APK выполните `android/gradlew -p android assembleDebug --no-daemon` (Windows: `android\gradlew.bat`). SDK задаётся в исключённом из Git `android/local.properties` либо переменной окружения. Результат находится в `android/app/build/outputs/apk/debug/`.

`npm run apk` собирает release APK и при первом запуске создаёт собственный ключ подписи. Ключ и `keystore.properties` не публикуются; сохраните их защищённую копию для обновлений. Старый ключ приложения не импортировался.

Новый application ID — `org.hotelmanager.app`. Адрес сервера и сертификат гостиницы отсутствуют, используется HTTPS с системным доверием либо с явно подтверждённым отпечатком сертификата. Нативный SecureHttp запрещает переадресации, проверяет срок и имя сертификата; фоновые запросы используют ту же проверку. Firebase конфигурация не включена; Firebase push отключён. Автоматическая установка APK отключена. Виджет не хранит сведения о гостях. Сборка не заменяет испытания на физическом устройстве, включая TLS и Android Keystore.
